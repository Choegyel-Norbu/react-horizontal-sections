A React UI library for every primitive

Shadcnblocks is a React UI library built on shadcn/ui and Tailwind CSS. All 2150 blocks and 2151 components are React components that work with Next.js, Vite, Astro and Remix, and every one of them is published for Radix UI, Base UI and React Aria. Pick the primitive library in components.json and the shadcn CLI installs the matching build.

Radix UI

Our recommendation. Every block is authored against the Radix UI wrappers first, so this is the most battle-tested path and what most existing Next.js projects run.

"style": "radix-vega" Radix UI blocks →

Base UI

Headless components from the MUI team, and now the shadcn/ui default for new projects. Blocks that touch primitive APIs ship a dedicated Base UI build, typechecked against the Base UI wrappers.

"style": "base-vega" Base UI blocks →

React Aria

BETA

Adobe's accessibility-first React Aria Components. Every block resolves for React Aria; where shadcn's preset is missing a wrapper we ship our own, which is why this one is still in beta.

"style": "aria-vega" React Aria blocks →
